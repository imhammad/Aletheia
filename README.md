# Aletheia

A full-stack platform helping CS students navigate their field, interactive visual explanations of core CS topics, an AI-driven career/skills advisor, and community-curated learning roadmaps.

## Status
In active development.

## Tech Stack
- Frontend: Next.js, TypeScript, Tailwind CSS, Framer Motion, React Flow
- Backend: Node.js (NestJS)
- Database/Auth: Supabase (Postgres)
- AI: Claude API

## Features (planned)
- [ ] Interactive CS topic visualizations
- [ ] AI-driven skills quiz & field recommendation
- [ ] Personalized learning roadmaps with resources
- [ ] Community-rated roadmaps
- [ ] Role-specific career plans
